# Cleanroom Results

This directory is reserved for manifest-backed cleanroom evidence bundles.

Subdirectories are created by later implementation tasks:

- `raw/` for raw solver and diagnostic outputs
- `reports/` for Markdown, CSV, and JSON summaries
- `figures/` for final rendered figures
- `source_data/` for figure source data
- `manifests/` for source, compile, run, and evidence manifests

Files in this tree are not scientific evidence unless they are referenced by a
manifest, pass schema checks, and carry an evidence-level label.
